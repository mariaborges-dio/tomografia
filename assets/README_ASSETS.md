# Assets clínicos para o MVP estático

Estes arquivos foram extraídos dos materiais do desenvolvimento já compartilhados no projeto. Use-os como conteúdo clínico real/exportado para compor as telas estáticas. Não herde a interface do protótipo antigo.

## Alinhamento
- `alinhamento/01_axial.jpg`
- `alinhamento/02_coronal.jpg`
- `alinhamento/03_sagital.jpg`

Use apenas para a tela de revisão de alinhamento.

## Parassagitais
- `parassagitais/00_panoramica_reconstruida.jpg`: referência panorâmica do conjunto.
- `parassagitais/01_referencia_axial.jpg`: referência axial.
- `parassagitais/corte_00.jpg` a `corte_11.jpg`: sequência parassagital do mesmo conjunto demonstrativo.

A tela hero deve priorizar estes assets.

## MPR
- `mpr/01_axial.jpg`
- `mpr/02_coronal.jpg`
- `mpr/03_sagital.jpg`

Use como apoio/conferência, sem transformar a tela em workstation técnica.

## 3D
- `3d/01_segmentacao_completa.jpg`
- `3d/02_segmentacao_frontal.jpg`
- `3d/03_segmentacao_rotacionada.jpg`
- `3d/04_segmentacao_reduzida.jpg`
- `3d/05_modelo_base.jpg`

Para a apresentação de amanhã, 3D pode ser ESTÁTICO. Não gastar tempo simulando interação.

## Regra importante
O foco do MVP é mostrar a proposta de **cortes preparados automaticamente**. Os assets existem para tornar essa proposta concreta, não para obrigar a criação de um software radiológico completo.
